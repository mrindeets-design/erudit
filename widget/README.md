# Эрудит Widget — Embeddable Chat Assistant

Изолированный браузерный виджет чат-ассистента для колледжа НОМОС, построенный на React + Vite с Shadow DOM для полной изоляции стилей.

## 🎯 Особенности

- **Shadow DOM изоляция** — стили виджета не конфликтуют с основным сайтом
- **4 адаптивных состояния**:
  - State 1: Свёрнутая аватарка с онлайн-индикатором
  - State 2: Hover-подсказка (только desktop)
  - State 3: Welcome screen с категориями
  - State 4: Полноценный чат с mock AI-ответами
- **Персистентность сессии** — сообщения сохраняются в localStorage
- **Полная адаптивность** — desktop, tablet, mobile
- **Академический дизайн** — темно-синий (#003B7A), белый, без неона

## 🚀 Разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production-версии
npm run build

# Проверка типов
npm run typecheck
```

## 📦 Сборка

Команда `npm run build` создаёт один файл `dist/erudit-widget.js` (IIFE формат) со встроенным CSS.

## 🔧 Интеграция на сайт

Добавьте перед закрывающим тегом `</body>`:

```html
<script src="https://your-cdn.com/erudit-widget.js"></script>
```

Виджет автоматически инициализируется при загрузке страницы.

## 🎮 API

```javascript
// Открыть виджет программно
window.NomosEruditWidget.open();

// Закрыть виджет
window.NomosEruditWidget.close();

// Версия виджета
console.log(window.NomosEruditWidget.version);
```

## 📂 Структура

```
src/
├── entry.tsx              # Точка входа с Shadow DOM
├── Widget.tsx             # Главный компонент с логикой состояний
├── types.ts               # TypeScript типы
├── styles.ts              # Все стили виджета
└── components/
    ├── AvatarButton.tsx   # State 1 + 2
    ├── WelcomeScreen.tsx  # State 3
    └── ChatScreen.tsx     # State 4
```

## 🎨 Дизайн

Виджет следует академическому стилю с визуальных референсов:
- Цвета: темно-синий (#003B7A, #002856), белый, оранжевый (#FF9800)
- Персонаж: кубический стиль с академической шапочкой, очками, наушниками
- Типографика: системные шрифты, читабельные размеры
- Без неона, без дешёвого 3D

## 🧪 Тестирование

Откройте `index.html` в браузере для локального тестирования виджета.

## 📱 Адаптивность

- **Desktop** (>768px): Полный функционал с hover-эффектами
- **Tablet** (769-1024px): Адаптированные размеры
- **Mobile** (<768px): Полноэкранный режим, скрытие tooltip

## 🔐 Безопасность

- Изоляция через Shadow DOM
- Нет external dependencies (кроме React)
- localStorage для хранения сессии (только на клиенте)
