# Инструкция по добавлению изображения аватара Эрудита

## Важно!

Для корректной работы виджета необходимо добавить изображение аватара Эрудита.

## Шаги:

1. **Сохраните третье предоставленное изображение** (аватар Эрудита с синей шапочкой, очками и книгой) как файл:
   ```
   src/assets/images/erudit-avatar.png
   ```

2. **Формат файла:** PNG с прозрачным фоном
3. **Рекомендуемый размер:** 400x400px или больше (будет масштабироваться автоматически)

## Что изображение используется:

- **AvatarButton**: Круглая кнопка внизу справа (64x64px)
- **WelcomeScreen**: Большой персонаж в hero-секции (180x180px)
- **ChatScreen**: Аватар в сообщениях от бота (40x40px)

## После добавления файла:

```bash
npm run build
npm run dev
```

## Если файл не добавлен:

Виджет будет работать, но вместо аватара будет показываться placeholder (прозрачное изображение или SVG иконки).

## Дополнительные изображения (опционально):

Для полного соответствия дизайну можно добавить:
- Фотографию здания колледжа для footer секции (пока используется placeholder градиент)
- SVG иконки категорий (сейчас используются простые SVG placeholders в синем цвете)

Все файлы должны быть размещены в: `src/assets/images/`
