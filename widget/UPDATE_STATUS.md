## ⚠️ Требуется действие пользователя

### Добавить реальное изображение аватара

**Файл:** `src/assets/images/erudit-avatar.png`

Сейчас используется прозрачный placeholder (400x400px). Нужно заменить его на **третье изображение**, которое было предоставлено (аватар Эрудита с синей академической шапочкой, золотыми очками и книгой).

**Как добавить:**
1. Сохраните третье изображение как `erudit-avatar.png`
2. Поместите в `C:\nomoserudit\widget\src\assets\images\`
3. Пересоберите проект: `npm run build`

**Характеристики изображения:**
- Формат: PNG с прозрачным фоном
- Рекомендуемый размер: 400x400px или больше
- Персонаж должен быть в центре

### Опционально: Дополнительные assets

**Изображение колледжа** для footer (сейчас используется gradient placeholder):
- Файл: `college-building.png` или `.jpg`
- Добавить импорт в `placeholders.ts`

**Иконки категорий** (сейчас используются простые SVG):
- Можно заменить на реальные SVG или PNG из дизайна
- Файлы: `admission.svg`, `specialties.svg`, `schedule.svg`, и т.д.
