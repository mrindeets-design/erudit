🎓 Тестирование виджета Эрудит

Это тестовая страница для embeddable виджета "Эрудит" — ИИ-помощника колледжа НОМОС.

Виджет использует Shadow DOM для изоляции стилей и не конфликтует с CSS основного сайта. Все данные сессии сохраняются в localStorage браузера.

Возможности виджета:

  • State 1: Свёрнутая аватарка с индикатором онлайн (правый нижний угол)
  • State 2: Hover-подсказка при наведении на desktop
  • State 3: Welcome screen с категориями быстрого доступа
  • State 4: Полноценный чат с mock AI-ответами
  • Адаптивность: Полная поддержка desktop, tablet и mobile
  • Персистентность: Сессия сохраняется при закрытии виджета

📋 Интеграция на сайт:

Добавьте этот код перед закрывающим тегом </body>:

<script src="https://your-cdn.com/erudit-widget.js"></script>
